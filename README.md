# Sistema de Dados Simples

Um sistema de cadastro de dados pessoais feito em Python, desenvolvido para fixar conceitos fundamentais da linguagem.

## 💡 Sobre o projeto

Este é um dos meus primeiros projetos desenvolvidos de forma independente.  
O objetivo foi praticar entrada de dados, validações e exibição formatada no terminal.

## ⚙️ Funcionalidades

- Coleta de nome, idade e time favorito
- Validação de campos em branco
- Validação de formato de idade
- Exibição organizada dos dados cadastrados
